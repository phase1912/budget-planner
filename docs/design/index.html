Design reference

Budget Agent screens

Every phase-1 screen, as it should look. These pages are the reference the implementation is checked against — when the built UI and a page here disagree, the built UI is wrong unless the change is made here in the same commit. See README.md and ADR 0004.

The screens link to each other, so you can click through the product as designed — start at the dashboard, open a receipt, walk the upload wizard.
