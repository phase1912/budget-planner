# scripts

Repository tooling — scripts that operate on the project itself, not on user data.
Not application code; nothing here runs in production.

| Script | Purpose |
|---|---|
| [`backlog_sync.py`](backlog_sync.py) | Projects `docs/planning/backlog.yaml` onto GitHub labels, milestones, issues and the Projects v2 board. See [the working agreement](../docs/planning/working-agreement.md). |
